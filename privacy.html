Privacy Policy

Effective 15 August 2026

Ancient Ordinary is a YouTube channel operated by an independent creator. Episodes are published using a private command-line tool written and run by that same person. This policy explains what that software handles, what this website collects, and how to revoke its access.

In short: the software has no users other than its owner. It collects no personal information from visitors, viewers or any third party. It reads and writes data for exactly one YouTube account — the owner’s own.

1. This website

This site is a set of static pages hosted on GitHub Pages. It has no accounts, no login, no comment system, no analytics, no advertising and no tracking cookies. We do not collect, store or share any personal information about visitors. GitHub, as the host, may process standard server request logs — see the GitHub Privacy Statement.

2. Use of YouTube API Services

The publishing software uses YouTube API Services to upload finished videos to the owner’s own channel and to read back information about those same videos.

By using our software you agree to be bound by the YouTube Terms of Service. Google’s handling of any data it receives is governed by the Google Privacy Policy.

Specifically, the software calls:

  • videos.insert — upload an original video to the owner’s own channel, at most once per day.
  • videos.list — read back the video just uploaded, to confirm its title and privacy status are correct.
  • channels.list — confirm the stored credential points at the intended channel before anything is uploaded.
  • YouTube Analytics — read views and audience retention for the owner’s own videos, to decide how long future episodes should be.

The software does not search YouTube, does not read any other user’s channel, videos, comments or subscriptions, and does not display YouTube data to anyone.

3. What is stored, and where

Two things are stored, both on the owner’s own computer, and neither is transmitted anywhere:

  • An OAuth 2.0 credential for the owner’s Google account, granting the scopes youtube.upload, youtube.readonly and yt-analytics.readonly. It is held in a file readable only by the owner’s user account.
  • The video ID returned by each successful upload, with a timestamp, in a local database, so the same video is never uploaded twice.

No video content, channel data, viewer data, comments or personal information belonging to any other person is ever stored.

4. Revoking access

The owner may revoke the software’s access to their Google account at any time from Google Security Settings → Third-party apps with account access. Revoking access immediately and permanently stops the software from being able to upload or read anything.

5. Deleting stored data

Because everything is held locally, deletion is immediate and complete: removing the credential file destroys the stored authorisation, and deleting the local database removes the record of past uploads. There is no server-side copy to request the deletion of, and no third party holds data on our behalf.

Videos already published can be removed at any time from YouTube Studio by the channel owner.

6. Children

This site and the channel are intended for a general adult audience. We do not knowingly collect information from anyone, including children.

7. Changes to this policy

If this policy changes, the revised version will be posted on this page with a new effective date.
