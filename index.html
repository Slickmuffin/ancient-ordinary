Ancient Ordinary

How ancient and pre-modern people actually lived, day to day.

Ancient Ordinary is a YouTube channel about ordinary life in the ancient and pre-modern world — sleep, food, work, medicine, hygiene, childhood and death. Not kings, not battles, not dates: the ordinary hour of an ordinary person, in a real time and a real place.

Watch the channel at youtube.com/@ancientordinary1.

About the publishing software

Episodes are produced with a private, single-operator command-line tool written by the channel’s owner. It writes an original script, generates illustrations for it, renders a narrated video, and uploads the finished file to the owner’s own YouTube channel using YouTube API Services.

The tool is not distributed, not sold, and has no users other than the owner. It does not access anybody else’s YouTube data.
